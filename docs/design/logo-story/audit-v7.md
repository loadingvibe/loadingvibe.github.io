# 第七版动画复核

日期：2026-09-20。预览：`/motion-review/`，欢迎页：`/?welcome=1`。

## 本轮变更

1. 重新建立肩部、身体、髋部、双腿的一体轮廓，移除独立腿模型和原身体下沿的横向拼接线。颜色连续延伸至腿部，不再在腿根重复原图底缘暗线。
2. 左肩改为沿连续中心线弯曲；正面和背面重新布置内部顶点、调整三角形连接。第一次轮廓插值方案发现翻面后已放弃，最终方案在全时段检查中未检出左肩指定区域三角面翻转。
3. 腿部在 3.60–3.98 秒随前景笔触到达连续缩回原图下沿；不再突然隐藏独立腿网格。保留左臂 2.62–3.75 秒抬起、原地轻跳、星光节奏及 6.2 秒总时长。
4. 审核页升级为 MOTION STUDY 07；撤掉已不适用的旧腿根嵌入、独立腿遮挡率和显隐切换指标，增加肩部翻面检查和收腿结束边界检查。

## 实际核验

- 实际角色网格按 60fps 采样 373 帧：坐标全部有限，人物根节点 X 始终为 0，归位后的目标网格误差 0，左肩指定区域三角面翻转 0。身体网格 27,444 个非索引顶点。
- 浏览器 1280×900 视口、画布 487,200 像素下检查全部 373 帧，并人工浏览全部 16 组逐帧缩略图；另外放大检查开场、左臂中间态、左臂归位、收腿和最终交接。
- 左手局部高度从 −0.564095 连续单调升至 0.444；最小手头间距指标 0.26249。该间距为手部锚点指标，不是完整表面碰撞测试。
- 笔尖与笔迹末端误差小于 6×10⁻¹⁶ 场景单位，握持误差 0；笔触中心线越界 0 帧，最大相邻采样帧位移 0.050674 场景单位；星光落定后漂移 0。
- 收腿完成边界前后平均像素差 0.009727（0–255），差异大于 2 的像素 29 / 487,200。此时笔触仍在正常运动；不是同一时刻的开关对照，也不宣称像素差全部由收腿引起。
- 原图交接进入/结束边界平均像素差 0.013471 / 0.011048（0–255）；两处差异大于 2 的像素均为 0，最终静止帧差异 0。不是模型与原图的相似度评分。
- 当前电脑 1× 播放记录 743 帧，帧间隔中位数 8.3ms、P95 9.3ms，超过 50ms 的帧为 0。仅代表本机此轮浏览器播放，不代表所有设备。
- 恢复浏览器原始窄面板尺寸后检查开场和左臂中间态，人物、黑板、手臂完整留在画面内。桌面视口覆盖已重置。
- 控制台保留了开发服务启动前的 Vite WebSocket 连接失败记录；本轮播放未观察到角色或渲染异常。不将历史连接记录写成动画运行错误，也不宣称控制台历史完全无错误。
- 最终构建通过：39 个文件的类型检查无错误、警告或提示；23 个路由、2 个站点地图的静态检查通过，差异空白检查通过。构建器仍提示 Three.js 分包超过 500KB，属于已有体积警告。
