# loadingvibe Logo 动画 · 第七版材料规范

更新：2026-09-20。当前预览：/motion-review/；第三至六版检查作为历史记录保留于各版 audit 文件。

## 本轮原则

以原始 Logo 的人物轮廓和厚涂纹理为优先；取消绕圈、横向居中移动与横向拉平遮腿。人物开场即彩色，保留写字、灵感、原地轻跳的故事。

## 造型与材料

- 唯一纹理源为 public/assets/brand/optimized/mark-768.avif。人物、黑板笔触和星光共用原图颜色，不再另配通用金色材质。
- 肩部、躯干、髋部、双腿共用一个闭合倒角轮廓；原图不对称 Y 形上半身保留，头部为单独圆顶，无脖子。取消身体下沿的横向边缘与独立腿模型，不再用两个曲面插入身体来掩盖接缝。
- 左缘青蓝、中央金黄、右缘橙红与原图对应。腰部往下采用连续纹理映射，避开原图躯干底缘的暗线，使颜色贯穿髋部、大腿和圆润收脚。腿并非原图原有结构。
- 左臂沿积分得到的连续中心线弯曲，再随笔触流动回到原图姿势，不在肩部设置单一折转点。正背面重新铺设内部顶点并调整三角形连接，避免狭长三角面在弯曲时翻折；右臂仍使用双关节权重写字。未新增建模依赖。
- 人物表面使用原图烘焙质感，不进行改变颜色的实时重新打光。这是固定正面镜头的三维浮雕，不是任意视角完整角色。
- 黑板为带厚度和倒角的石墨面板、暖白边框、深灰背板，置于人物右侧；边框不参与形成 Logo。黑板绘图仅包含六条笔触，不包含星光。
- 六条独立笔触采用 88 个纵向段、12 段椭圆截面。中心线和宽度分段对照原图，修复偏细、末端切平；原图透明纹理保留不规则笔触边缘。
- 星光取原图形状，从原位下方 0.16 场景单位向上到达人物右上方的原图位置，每颗 0.68 秒；透明度前 0.42 秒渐显，尺寸由 0.52 平滑到 1。下方光芒先行、上方星星和圆点稍后，最多错开 0.20 秒；到位后固定，无弹跳或过冲。不替换成通用星形；关闭星光材质的 alpha 裁剪，保留低透明度细节。全组结束约 0.07 秒后开始笔触移动。
- 旧 logo-layers/ 仅作为参考，不用于当前动画。

## 运动

- 人物根节点 X 始终为 0，只做纵向预备和轻跳。右臂在 2.43 秒恢复源网格；画面左臂开场自然放低，2.62–3.75 秒随笔触流动抬起，3.75 秒两臂均回到原图姿势。头部与身体不再横向归中。
- 最后一笔是石墨弧剩余 37%；笔尖与笔画使用同一条中心曲线，不额外生成独立涂鸦。
- 写字末端采用连续的分段内插值，不再按完整网格段跳进；末端 UV 同步，保持原图纹理。笔固定在手腕上，通过双关节反解触及笔迹，不再把笔单独放到笔迹位置。1.62–1.86 秒轻轻抬笔，1.76–2.04 秒淡去笔杆。
- 每条笔触独立从黑板向自己的最终位置移动，错开 0.14 秒；沿线细小的时间差与纵深弧线保持流动感，不绕圈、不先合并，也不先拉成横向带片。
- 黑白笔触使用浅后层，保证刚离板时不穿到板后；彩色笔触向前运动。真实网格的前后遮挡与椭圆截面保留空间层次。
- 3.60–3.98 秒，双腿在到达的前景笔触遮挡下，连续缩回原图下沿；同一网格的纹理坐标同步恢复至原图。没有独立腿部的显隐切换或透明度淡出，整个人不横移。检查收腿结束边界两侧的实际画布像素；不再使用旧版独立腿部嵌入和遮挡率指标。
- 主要过渡使用五次缓动，归位端的速度、加速度为零。
- 5.42–5.98 秒在两个完整渲染帧间交接，避免直接叠盖原图而残留旧轮廓。线性颜色空间合成并正确处理预乘透明度；支持时用半浮点目标保留暗部色彩精度，不支持则退回 8 位目标。交接目标与实际画布像素尺寸一致。6.20 秒恢复静态图片并释放三维渲染器。原图补足笔触边界细节，不应描述成逐像素完全一致的角色变形。
- 保留欢迎文字的渐显上浮风格，延迟同步至 5.10–5.50 秒开始，均在动画结束前完成。

## 性能与验证边界

DPR 上限 1.5；不启用阴影贴图；两臂和双腿归位后缓存身体姿态。变形网格在绘制前更新包围球，保持透明排序信息一致，审核不再改变这部分状态。保留按需加载、回访跳过、减少动态效果、资源失败/超时/WebGL 失败静态降级、后台暂停、结束资源清理逻辑。

审核页支持 1×/0.5×/0.25×、逐帧、关键时刻、373 帧接触表及 JSON；提供开场腿形、星光上升、左手抬起/归位和原图交接停靠点。加载和全帧检查期间禁用控制，避免争用时序。数值检查包括有限坐标、中心线边界、人物 X、归位网格误差、星光停稳、笔尖/连续笔迹末端误差、握持误差、左手抬升单调性，以及左肩指定区域正面三角形翻转；另比较交接及收腿结束边界两侧的实际画布像素。这些不是完整网格碰撞、与原图逐像素相似度或美术品质的自动证明。

最新验证见 audit-v7.md。若全身腿部仍不获认可，削减方案是取消腿与跳跃，保留原图上半身、局部写字、星光和独立笔触直接归位。未擅自启用该削减方案。
