# 第六版动画复核

日期：2026-09-19。预览：`/motion-review/`，正式欢迎页：`/?welcome=1`。

## 本轮变更

1. 星光每颗约 0.68 秒，由下向上渐显，全组 1.67–2.55 秒；到位后固定。恢复更紧凑的 6.2 秒全片节奏。
2. 腿根从尖点改为有宽度、嵌入身体的连续大腿；重做膝部、脚踝和圆润收脚，颜色从原图身体下部延续。
3. 画面左手开场放低，2.62–3.75 秒伴随条纹流动抬至原图姿势；肩部混合旋转角，减少塌陷。
4. 收腿向后并向内，收拢后原图身体的半透明笔触会透出腿部底色，因此补充末段 0.14 秒淡出，避免隐藏网格导致局部变色。
5. 变形后刷新透明排序所用的包围球；新增腿根、左手抬升和隐藏腿部的独立像素检查。

## 实际核验

- 60fps 采样 373 帧，并人工浏览 16 组全帧缩略图；放大检查开场腿根、抬臂中间态、归位和收腿边界。
- 非有限坐标 0，笔触中心线越界 0 帧；人物根节点横移 0；两臂归位后的源网格误差 0。
- 左手高度单调上升，局部高度从 −0.496882 到 0.444；最小手头间距指标 0.26249。
- 6 个腿根检测位置全部位于身体后方；隐藏附近 24 个实际腿部表面采样点的遮挡率 100%。这些是几何采样，不是完整像素遮挡率。
- 星光落定后漂移 0；另用数学断言验证九个星光元素的高度、透明度和尺寸单调变化，结束值精确归位。
- 写字笔尖/笔画末端误差小于 6×10⁻¹⁶ 场景单位，握笔误差 0。
- 隐藏腿部独立对照：在同一时刻只切换腿部可见性，1,096,200 像素中差异为 0。修正前有 735 个像素的差异超过 2/255，集中在半透明身体内部。
- 隐腿边界前后平均像素差 0.010783/255；相同时距的正常运动对照为 0.010687/255。相邻帧仍有正常笔触运动，不将它们误报为隐藏腿造成的突变。
- 原图交接进入/结束边界平均像素差约 0.01205 / 0.01049（0–255）；最终静止帧差异为 0。不是模型与原图逐像素相似度测试。
- 当前电脑正常速度播放记录 738 帧，间隔中位数 8.3ms、P95 8.4ms，超过 50ms 的帧为 0。仅代表本机浏览器，不代表所有手机或低性能设备。
- 390×844 窄屏检查开场和抬手中间态，人物、黑板与手臂均在画面内。
- 浏览器无警告/错误；构建通过：37 个文件无类型错误、警告或提示；23 个路由、2 个站点地图的静态检查通过。构建器仍提示 Three.js 分包超过 500KB，属于已有体积警告。
