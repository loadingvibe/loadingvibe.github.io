# Loading Vibe — 参考站设计提炼

## 可借鉴的形式

| 参考站 | 核心形式 | 值得借鉴 | 本站的转译 |
| --- | --- | --- | --- |
| Dwarkesh Podcast | 视频首屏 + 长文正文 + 侧栏 | 强内容主次、可持续阅读、平台入口集中 | 把“深度”变成编辑部式留白与清晰信息层级 |
| 20VC | 满版人物照片 + 超大窄体标题 | 首屏冲击、栏目感、节奏快 | 用超大字和节目封面墙制造能量，不复制其摄影或品牌字标 |
| Spotify / 小宇宙 | 节目封面 + 明确播放动作 + 紧凑列表 | 识别快、行动路径短、移动端友好 | 每张节目卡都保留一眼可见的封面、类别和外链收听入口 |
| Acquired | 大留白 + 方形视觉档案网格 | 把节目当成可收藏的“故事目录” | 提供 Cover Wall 海报墙视图，让 8 档节目形成视觉索引 |
| 硅谷101 / Fireside | 节目信息、主持人、订阅渠道、季归档 | 信息完整、结构朴素、长期可维护 | 使用语义化内容、筛选标签和紧凑列表视图 |

## 三个设计方向

### A. 深读编辑部

- 关键词：克制、可信、长阅读
- 构成：暖纸色、宋体标题、窄内容栏、细规则线
- 对应参考：Dwarkesh、硅谷101

### B. 媒体海报

- 关键词：直接、快速、强对比
- 构成：黑色首屏、超大无衬线字、封面拼贴、朱橙信号色
- 对应参考：20VC

### C. 节目书架

- 关键词：可浏览、可收藏、封面优先
- 构成：规则方格、统一元数据、紧凑动作、三种密度
- 对应参考：Acquired、Spotify、小宇宙

## 最终选型

使用 A 的信息骨架、B 的首屏表现力、C 的节目目录。页面默认采用 Editorial Grid，并允许切换到 Cover Wall 与 Compact List；这三种视图不是换颜色，而是分别改变内容层级、密度和浏览节奏。

## 视觉系统

- 字体：中文标题使用 `Songti SC / STSong`，正文使用 `Microsoft YaHei`，标签使用 `Cascadia Mono`；不依赖远程字体。
- 色彩：纸色 `#F2EEE5`、墨色 `#11110F`、朱橙 `#F4511E`、辅助灰 `#79766F`。
- 字号：展示字 `clamp(64px, 13vw, 186px)`；章节标题 `clamp(40px, 6vw, 88px)`；正文 16–18px。
- 间距：8px 基础网格；主要节奏为 24 / 32 / 48 / 72 / 120px。
- 版式：12 栏桌面网格、移动端单栏；封面始终保持 1:1。
- 动效：短促位移和遮罩揭示；遵循 `prefers-reduced-motion`。
