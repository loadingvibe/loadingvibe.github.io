# 4. 快捷指令

- command+/：查看源码（typora）

- command+shift+。：查看隐藏文件夹

  ![image-20260816095840712](./01-envirnonment-buildproject.assets/image-20260816095840712.png)

- ls -la：查看当前路径下所有文件或文件夹包括隐藏文件
- -+空格：黑点
- Pip list:查看当前安装了什么包
- deactivate:推出虚拟环境
