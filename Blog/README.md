# Blog 作者入口

`Blog/` 中的 `.md`、`.markdown` 和 `.txt` 文件都是独立文章。文件和文件夹可以使用中文、英文、空格以及多层目录。即使正文内容相同，只要源文件不同，站点也会全部保留。

最简单的写法是直接写正文，不需要先填元数据：

```md
# 今天学到的东西

从这里开始记笔记。
```

`Blog/` 最外层的每个普通文件夹都会成为阅读页的一个门类，名称与文件夹完全一致，并带有图标。嵌套文章归入最外层文件夹；直接放在 `Blog/` 中的文章归入「未分类」。以 `_` 或 `.` 开头的目录及 `.assets` 资源目录不会成为门类。

门类内按创建时间从新到旧排列，时间相同则按源文件路径的自然顺序排列。可以使用 `created`、`createdAt` 或 `创建时间` 固定创建时间；省略时依次使用文章日期或路径日期、Git 首次加入记录、文件创建时间。修改时间不参与排序。

运行 `npm run dev` 后打开终端显示的本地网址，保存文件即可看到更新。新增、重命名或删除文章与文件夹都会更新目录。空文件夹也会显示；要通过 Git 保留并部署空门类，可在其中放一个 `README.md`。设置了 `draft: true` 的文章可以在本地开发中预览，正式构建时会排除。

请按 [Markdown 写作与发布说明](../docs/AUTHORING.md) 新建、下线或删除文章。

> 这个 README 仅是仓库内的作者说明，不会被发布成博客文章。
