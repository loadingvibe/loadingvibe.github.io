# 如何在这里写博客

这个网站会自动读取 `Blog` 文件夹中的所有 Markdown 文件。你可以直接新建 `.md` 文件，也可以按主题继续创建任意层级的文件夹。

## 文章信息

在文件顶部加上下面这段信息：

```yaml
---
title: 文章标题
date: 2026-08-13
summary: 用一两句话介绍文章。
tags:
  - 技术
  - 随笔
---
```

`title` 、`date` 、`summary` 和 `tags` 都是可选的。如果暂时不想发布，可以加上 `draft: true`。

## 数学公式

行内公式使用一对美元符号，例如 $E = mc^2$。

独立公式使用两对美元符号：

$$
\int_{-\infty}^{\infty} e^{-x^2}\,dx = \sqrt{\pi}
$$

> 保持记录。文件夹是书架，Markdown 就是你的纸。
