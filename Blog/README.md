# Blog 作者入口

`Blog/` 中的 `.md`、`.markdown` 和 `.txt` 文件都是独立文章。文件和文件夹可以使用中文、英文、空格以及多层目录。即使正文内容相同，只要源文件不同，站点也会全部保留。

最简单的写法是直接写正文，不需要先填元数据：

```md
# 今天学到的东西

从这里开始记笔记。
```

运行 `npm run dev` 后打开终端显示的本地网址，保存文件即可看到更新。新增、重命名或删除文章也会更新目录。设置了 `draft: true` 的文章可以在本地开发中预览，正式构建时会排除。

请按 [Markdown 写作与发布说明](../docs/AUTHORING.md) 新建、下线或删除文章。

> 这个 README 仅是仓库内的作者说明，不会被发布成博客文章。
